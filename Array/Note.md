**Array**{
    -> Linear Data Structure that allow us to store multiple values of same type in **contiguous** memory location.
    > in order, sequential

    + Characteristic:
        _ Contiguous Memory :
        _ Indexed : Use index to access the element
        _ Homogeneous : Same data type, same type

**Types Of Array**{
    _ Static Array(Stack-Allocated) : Stored on stack. 
    _ Dynamic Array(Heap-Allocated) : Stored on heap.
}

**Allocate**: declare the location to store value
**Deallocate**: delete + location = clear / delete memory access that we used all store values before 

};
